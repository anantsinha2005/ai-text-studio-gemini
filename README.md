# AI Text Studio — Project 9

AI-powered text generation web app built with Node.js, Express, and the OpenAI API. Generate emails, social posts, product descriptions, summaries, ideas, and more with adjustable tone and length.

## Requirements
- Node.js 18+
- OpenAI API key

## Setup
1. Run `npm install`
2. Copy `.env.example` to `.env`
3. Add your API key to `.env`
4. Run `npm start`
5. Open http://localhost:4000

Your API key stays server-side and is not exposed to the browser.
